# SMS Spam Detection

Machine learning-based SMS spam classification using TF-IDF feature extraction and Linear Support Vector Machine (SVM).

## Tech Stack
- Python
- TF-IDF
- Linear SVM
- Jupyter Notebook

## My Contributions
- **Character-Level TF-IDF:** Implemented character-level feature extraction experiments for SMS classification.
- **Linear SVM:** Worked on text classification using a Linear Support Vector Machine model.
- **Multilingual Experiments:** Explored language-based approaches for SMS spam detection across English and Hindi datasets.
- **Model Development:** Contributed to the classification and prediction modules.
